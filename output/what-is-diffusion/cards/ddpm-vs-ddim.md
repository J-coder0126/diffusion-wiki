# 證據卡：DDPM vs DDIM 取樣

> 來源頁面：wiki/comparisons/ddpm-vs-ddim.md（原文擷取，不改寫）

- DDPM 和 DDIM 用的是**同一個訓練好的模型**，差別只在取樣方式：DDPM 隨機、步數多；DDIM 確定、步數少也能維持品質。[DDIM §4.1][DDIM §5]
| 訓練目標 | L_simple（預測雜訊） | 與 DDPM 相同，不必重新訓練 | [DDIM §3][DDIM §5] |
| 前向過程 | 馬可夫鏈 | 非馬可夫的推廣 | [DDIM §3.1] |
| 生成過程 | 每步加入隨機雜訊（η = 1） | 確定性，不加雜訊（η = 0） | [DDIM §4.1] |
| 常用步數 | 1000 | 20–100 | [DDPM §4][DDIM §5.1] |
| CIFAR10 FID（20 步） | 明顯較差 | 6.84 | [DDIM Tab. 1] |
| CIFAR10 FID（1000 步） | 3.17（σ̂ 版本） | 4.04 | [DDIM Tab. 1] |
| 同一個 x_T 重新生成 | 每次結果不同 | 高層特徵一致 | [DDIM §5.2] |
| 潛在空間內插、重建 | 做不到語意內插 | 可以 | [DDIM §5.3][DDIM §5.4] |
- 要快、要可重現、要做內插或編碼：用 DDIM 少步數取樣。[DDIM §5.1][DDIM §5.2]
- 不在乎時間、跑完整 1000 步時，DDPM 的 FID 略好。[DDIM Tab. 1]
