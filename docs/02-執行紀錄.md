# 實際執行紀錄（檢查與修正）

> 記錄每次 lint／檢查關卡發現的問題、處理方式，以及因此對 workflow 做的調整。

## 2026-11-18｜初始化
- **發現**：第一次 commit 時 lint 回報 `wiki/timeline.md` 是孤兒頁，但 commit 仍然成功——因為「跑 lint」和「commit」是兩個獨立指令，AI 沒等 lint 結果就 commit 了。
- **處理**：孤兒頁是骨架階段的正常狀態（還沒有論文頁連到時間軸），第一篇 ingest 後會消失。
- **workflow 調整**：把檢查從「AI 自己記得跑」往前移到「git 強制執行」——新增 `.githooks/pre-commit`，lint 沒過就擋下 commit（`git config core.hooksPath .githooks`）。

## 2026-11-18｜ingest DDPM
- **lint 第 1 次**：✗ 斷掉的連結 `papers/ddpm.md → [[ddpm-vs-ddim]]`。原因：AI 預先連到「之後才會建立」的比較頁。
- **處理**：先移除該連結，等 DDIM ingest 建好比較頁再加回。
- **lint 第 2 次**：✓ 通過 → commit。
